Modèles de messages pour donner le lien

Ici : textes prêts à copier pour envoyer l’URL (et le code si besoin) par mail ou message.

Remplacez tout texte entre crochets par vos informations réelles. Supprimez les lignes qui ne s’appliquent pas (par ex. le code si la page est ouverte sans mot de passe). Retour au guide Liens & partage.

E-mail — premier cercle

Objet suggéré : [À compléter : objet type « Page souvenir de [Prénom] »]

Corps du message

Bonjour [Prénom],

Comme convenu, voici le lien vers la page hommage de [Nom de la personne aimée] :
[LIER L’URL COMPLÈTE ICI, en https://…]

[SI CODE : Pour l’ouvrir, il vous sera demandé le code suivant (à garder entre nous) : ________]

N’hésitez pas à me dire si le lien s’ouvre bien sur votre téléphone.

Je vous embrasse,
[Votre prénom]

E-mail — cercle élargi

Corps du message

Bonjour,

La famille a souhaité regrouper quelques textes et photos en mémoire de [Prénom Nom]. Vous pouvez les consulter ici :
[URL]

[SI CODE : Code d’accès : ________ (merci de ne pas le diffuser publiquement).]

Bien à vous,
[Nom du ou de la contact famille]

SMS ou message court

Exemple (< 300 caractères à ajuster)

Bonjour, voici la page en mémoire de [Prénom] : [URL courte ou lien] — code si besoin : [CODE]. Bises, [Prénom].

Texte pour faire-part ou cérémonie (optionnel)

Formulation sobre — à adapter avec le célébrant

Un espace de souvenir a été préparé : [URL]
[SI CODE : Code d’accès communiqué sur place / par la famille.]
Un QR présent sur [la plaque / le support] permet également d’y accéder.

À compléter : accord avec les lieux (crématorium, mairie) sur mention du numérique.

Checklist studio — avant d’envoyer le lien au client

Usage interne Mémoire & Présence — cochez au fil des projets.

  • URL finale en HTTPS, testée sur mobile (4G) et bureau.
  • Code d’accès testé (si applicable) — noter la référence projet / CRM.
  • QR sur maquette PDF ou photo testé sur 2 téléphones minimum.
  • E-mail récap envoyé depuis à compléter : adresse d’expédition officielle.
  • À compléter : pièce jointe type (PDF récap, pas de mots de passe en clair dans le sujet).
  • Client informé du délai / nombre de corrections inclus après livraison.
