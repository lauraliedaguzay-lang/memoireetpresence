Après la livraison

Recevoir le lien et le faire connaître aux proches

Ici : après livraison, comment utiliser l’URL, un éventuel code et le QR gravé.

Une fois la page hommage prête et, le cas échéant, la plaque expédiée, vous disposez de plusieurs moyens d’accès : adresse web (URL), code confidentiel si vous l’avez choisi, et QR code gravé sur le support. Cette page résume le geste à tenir ; des modèles de messages prêts à compléter sont disponibles séparément.

Ce que nous vous transmettons

En principe, vous recevez un e-mail récapitulatif (et, si besoin, un échange oral) contenant notamment :

  • Le lien direct vers la page hommage (adresse en https://).
  • Le code d’accès, uniquement si la page est protégée par code — mot de passe discret choisi avec vous, à compléter : politique de renouvellement du code si changement.
  • Un rappel pour tester le QR sur au moins un téléphone avant la pose de la plaque.
  • À compléter : délai d’ajustements mineurs inclus après livraison.
  • À compléter : coordonnées pour toute question technique (e-mail / téléphone dédiés).

Conservez cet e-mail (ou imprimez-le) : il sert de référence si un proche vous demande comment accéder à la page.

L’adresse web (URL)

La page a une adresse du type :

https://votre-domaine.fr/hommage/nom-du-projet/

Elle n’est en général pas listée sur notre site vitrine : on y accède par le lien que vous transmettez, par le QR, ou depuis l’historique du navigateur après une première visite.

Avant d’annoncer le lien à plusieurs personnes, ouvrez-le une fois sur téléphone en 4G (pas seulement en Wi-Fi à la maison) pour vérifier l’affichage.

Le code d’accès

Si vous avez opté pour une page protégée, le code est communiqué en privé (e-mail, message, oral). Il est préférable de ne pas le publier sur un réseau social ou un faire-part grand public.

À compléter : procédure si oubli du code ou changement de téléphone (contact studio).

Le QR sur la plaque

Les visiteurs du lieu (cimetière, columbarium, domicile…) peuvent scanner le QR avec l’appareil photo du téléphone : ils sont alors renvoyés vers la même page. Dans ce cas, ils n’ont pas besoin de recopier l’URL — seulement du code, si la page en comporte un après le scan.

Comment en parler aux proches

Chaque famille choisit son rythme. Souvent, on commence par un message court aux personnes les plus proches (lien + code si utile), puis on élargit. Nous proposons des formulations types dans la page Modèles de messages à personnaliser.

À compléter : phrase type sur la discrétion / l’absence d’obligation de publication sur les réseaux.
