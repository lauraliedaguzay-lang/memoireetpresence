Demander un devis, simplement

Ici : une demande courte, puis un devis clair — sans engagement.

On vous répond avec une proposition lisible (et honnête) : ce qui est inclus, le délai, et les options utiles — pas un catalogue.

Ce que vous recevez

  • Une proposition cadrée : page, accès, support, options utiles (et ce qu’on écarte)
  • Un délai réaliste. Si vous avez une date proche, on propose un plan en deux temps (V1 puis V2)
  • Une ligne claire sur la confidentialité : par lien/QR, et option accès par code si vous le souhaitez

Le plus simple pour avancer

Pour chiffrer juste, il nous faut souvent seulement deux informations : la date (s’il y en a une) et le volume (quelques éléments ou beaucoup). Ensuite, on vous renvoie un devis lisible et on ajuste si nécessaire.

Trois niveaux (pour rester lisible)

Plutôt que de vous noyer, nous cadrons en général l’hommage dans l’un de ces niveaux — puis nous affinons.

  • Essentielle : sobre, rapide, peu d’allers-retours — parfait si vous avez l’essentiel
  • Signature : mise en récit + harmonisation — pour un rendu plus “à son image”
  • Héritage : gros volume + accompagnement — si vous voulez construire une vraie transmission
