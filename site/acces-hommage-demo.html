Voir une page hommage avant de commander

Les hommages livrés peuvent être protégés par un code avant d’afficher le contenu. Ici, les maquettes en ligne reproduisent ce geste : écran « Accès réservé », puis la page après saisie du bon code. Pour un projet réel, le code est choisi avec vous, ne figure pas sur le site public, et une vérification côté serveur reste recommandée pour une sécurité forte — ce que vous voyez ici illustre surtout le parcours et le soin du design.

Code d’essai

memoire (tout en minuscules, sans espace)

Valable pour les deux maquettes ci-dessous. Après une saisie correcte, l’accès reste ouvert le temps de la session sur cet appareil (sessionStorage). Fermer l’onglet ou le navigateur peut redemander le code.

Sur mobile : menu du site via l’icône en haut à gauche ; sur la page hommage, faites défiler la galerie au doigt ou utilisez les points sous l’image.
