# Lien permanent à partager

## Avant déploiement sur le domaine (prévisualisation — Netlify)

**Pour avoir un lien cliquable tout de suite :** `**SITE-CLIQUABLE-MAINTENANT.md`** (Netlify Drop, ~1 min).

**Lien à envoyer aux clients** après votre premier déploiement sur Netlify (voir aussi `**ACTIVER-LIEN-DEMO-CLIENTS.md`**) :

```
https://VOTRE-SITE.netlify.app/
```

Remplacez `**VOTRE-SITE**` par le nom exact affiché par Netlify (ex. `memoire-presence-demo` → `https://memoire-presence-demo.netlify.app/`).

**Phrase type dans le mail :** *« Aperçu du site — l’adresse officielle sera [https://www.memoire-et-presence.fr/](https://www.memoire-et-presence.fr/) une fois en ligne. »*

*(L’ancien lien `github.io` n’est plus utilisé : passer par Netlify évite le 404.)*

---

## Après déploiement (lien officiel)

**Utilisez uniquement ce lien** sur les cartes, QR codes, e-mails, réseaux sociaux et documents : il reste **le même** tant que le site est hébergé sur ce domaine (renouvellement du nom de domaine à prévoir chaque année chez le registrar).

```
https://www.memoire-et-presence.fr/
```

*(Copier la ligne ci-dessus sans espace après le dernier `/` si besoin.)*

---

**À ne pas graver sur une plaque ou une carte** (sauf démo courte) : URL temporaire d’hébergeur du type `https://xxx.hostinger.com/...`. Le lien **netlify.app** sert **jusqu’à** la mise en ligne du domaine ; le lien **définitif** reste `https://www.memoire-et-presence.fr/`.

Si un jour le domaine change, il faudra mettre à jour ce fichier **et** le site avec le prestataire ; jusqu’alors, un seul lien suffit.
