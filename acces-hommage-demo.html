La porte d’accès sur les pages hommage de démonstration

Les vraies pages hommage livrées aux familles peuvent être protégées par un code avant d’afficher le contenu. Les maquettes en ligne reproduisent ce dispositif : vous voyez d’abord l’écran « Accès réservé », puis la page après saisie du bon code.

Code d’essai (démonstration uniquement)

Pour toutes nos URLs de démo listées ci-dessous, le code factice est le même (saisie en minuscules) :

memoire

Après une saisie correcte, l’accès reste ouvert pour la durée de votre session sur cet appareil (stockage sessionStorage du navigateur). Fermer l’onglet ou le navigateur peut redemander le code.

Pages à tester

  • Maquette « Famille Martin » — structure sobre, texte centré sur la mise en page technique.
  • Exemple « Claire Fontenay » — texte de souvenir fictif, encadré type cérémonie (données inventées).

En production

Le code réel est choisi avec la famille et ne figure pas sur le site public. Pour une sécurité forte, une vérification côté serveur est recommandée ; les fichiers statiques illustrent uniquement le parcours et l’interface.
