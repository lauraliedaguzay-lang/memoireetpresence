Voir une page hommage avant de commander

Deux façons de présenter un hommage, en démo : Claire Fontenay — tout de suite sous les yeux (idéal pour un aperçu ouvert) · Famille Martin — une entrée par code, comme quand on partage le lien seulement aux proches. Deux maquettes — accès réservé et accès libre

Même qualité de page, deux intentions : montrer le design sans friction, ou reproduire le moment d’entrée d’un hommage un peu plus intime.

Accès réservé (démo)

Famille Martin

Maquette sobre : portrait, textes, panneau souvenir, carrousel — avec porte d’entrée par code pour illustrer un hommage transmis en privé.

Code d’essai pour la démo : presence (sur un projet réel, ce serait un mot de passe que vous choisissez ou que nous vous transmettons).

En ligne, cette démo peut vérifier le code côté serveur selon l’hébergeur — l’important pour vous est le ressenti : vos proches comprennent tout de suite qu’ils arrivent dans un espace dédié.

Accès libre (démo)

Claire Fontenay

Maquette plus éditoriale : souvenir, encadré type cérémonie (fictif), galerie — tout le contenu est visible sans code.

Pour comparer le rendu lorsqu’on souhaite montrer la page telle quelle (aperçu client, portfolio).
