## Guide de création pour tous les formats

## Palette exacte (à saisir dans Canva : Couleurs de marque)

| Nom | Code HEX | Usage |
|-----|----------|-------|
| Sable fond | `#F7F4EF` | Fond principal de tous les visuels |
| Vert sauge | `#6E8870` | Accents, cadres, icônes |
| Vert forêt | `#3D6B4F` | Titres forts, CTA |
| Ardoise | `#2C3E41` | Texte principal |
| Crème | `#E8DCC8` | Fond alternatif, séparateurs |
| Blanc pur | `#FFFFFF` | Texte sur fond sombre uniquement |

## Typographie (à installer dans Canva)

| Rôle | Police | Style | Taille |
|------|--------|-------|--------|
| Titre post | Cormorant Garamond | Italic | 48–72px |
| Sous-titre | Cormorant Garamond | Regular | 32–40px |
| Corps texte | Source Sans 3 | Regular | 18–22px |
| Kicker / label | Source Sans 3 | SemiBold majuscules | 14px |

## Règles visuelles absolues

### ✅ Toujours
- Fond sable `#F7F4EF` ou photo en tons chauds
- Texte lisible : fort contraste (ardoise sur sable, blanc sur vert)
- Logo M&P présent mais discret (coin bas, max 80px)
- Marges généreuses (min 5% de chaque côté)
- Maximum 2 couleurs par visuel + blanc/crème

### ❌ Jamais
- Fond blanc pur seul (trop froid)
- Fond noir (trop dramatique pour le secteur)
- Plus de 2 polices différentes
- Emojis dans le visuel (seulement dans la légende)
- Filtres Instagram (Clarendon, Nashville, etc.)
- Photos de personnes décédées réelles
- Logos de concurrents ou prestataires

## Photos à utiliser (libres de droits)

Sources recommandées : **Unsplash**, **Pexels**, **Stocksy**

Mots-clés de recherche :
- `cemetery peaceful light` (cimetières lumineux)
- `memorial stone nature` (pierres naturelles)
- `family memories warm` (famille, chaleur)
- `garden flowers morning` (jardin, fleurs)
- `handcraft artisan stone` (artisanat, gravure)
- `autumn leaves calm` (automne, sérénité)

**À éviter :** cercueil, fleurs funèbres noires, larmes, noir et blanc dramatique.

## Workflow de création

```
1. Claude génère les specs visuelles (lundi 8h, dans le Google Doc)
2. Ouvrir Canva → dupliquer le template de la semaine
3. Suivre exactement les specs du post (couleur, texte, photo)
4. Exporter en JPG 1080px (IG) ou MP4 (Reels/TikTok)
5. Uploader dans Buffer/Later selon le planning
```
